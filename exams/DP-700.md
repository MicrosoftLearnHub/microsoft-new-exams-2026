## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
What is the core architecture pattern of Microsoft Fabric's 'OneLake'?

- **A)** Multiple disconnected proprietary file formats across regions
- **B)** A single, unified, logical data lake for the entire organization built on Azure Data Lake Storage (ADLS) Gen2 using open-standard Delta Parquet format
- **C)** Traditional local hard drive shares
- **D)** CSV files stored in SharePoint libraries

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** OneLake is the 'OneDrive for data'—a single SaaS multi-tenant lakehouse storage layer that eliminates silos by standardizing on Delta Parquet format.

---

### Question 02
**Scenario / Problem Statement:**  
Which Microsoft Fabric feature allows data engineers to reference data stored in external ADLS Gen2, Amazon S3, or Google Cloud Storage without data movement or replication?

- **A)** OneLake Shortcuts
- **B)** Manual FTP copy
- **C)** Database Backup and Restore
- **D)** Excel Import wizard

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** OneLake Shortcuts create symbolic links to external data lakes, allowing Fabric compute engines to query data in-place with zero data movement or duplication costs.

---

### Question 03
**Scenario / Problem Statement:**  
You need to ingest high-frequency real-time telemetry from IoT sensors, perform stateful windowed aggregations, and output alerts with sub-second latency. Which Fabric workload is optimized for this?

- **A)** Fabric Real-Time Intelligence (Eventhouse / KQL Database & Eventstreams)
- **B)** Excel 2016 manual refresh
- **C)** PowerPoint presentation slide
- **D)** Access Database

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Fabric Real-Time Intelligence leverages KQL Databases (Kusto engine) and Fabric Eventstreams for high-throughput, low-latency streaming analytics.

---

### Question 04
**Scenario / Problem Statement:**  
In Microsoft Fabric, what is the difference between a Lakehouse and a Data Warehouse?

- **A)** There is no difference
- **B)** A Lakehouse supports ACID transactions on files via Spark and SQL endpoints, while a Warehouse provides an enterprise T-SQL relational engine with full DDL/DML support over Delta format
- **C)** A Lakehouse only stores images, while a Warehouse only stores text
- **D)** A Warehouse cannot connect to Power BI

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Both share OneLake and Delta Parquet, but Lakehouses allow data engineering with Apache Spark notebooks, while Warehouses provide enterprise T-SQL data warehousing capabilities.

---

### Question 05
**Scenario / Problem Statement:**  
Which tool in Microsoft Fabric provides visual low-code data transformation with over 300 prebuilt connectors, similar to Power Query?

- **A)** Dataflow Gen2
- **B)** Notepad
- **C)** Command Prompt
- **D)** Calculator

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Dataflow Gen2 is Fabric's modern low-code ETL engine that loads transformed output directly into Lakehouses, Warehouses, or Azure SQL DBs.
