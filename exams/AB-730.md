## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
Which element of an effective prompt provides the AI with boundaries on tone, structure, output length, and target persona?

- **A)** Goal / Objective
- **B)** Context / Constraint
- **C)** Raw unformatted string
- **D)** Empty space

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Context and Constraints define the operational sandbox—specifying format (e.g., table vs bullet points), tone (e.g., executive, technical), and constraints (e.g., under 300 words).

---

### Question 02
**Scenario / Problem Statement:**  
How does referencing a specific document (e.g., '/filename.docx') in Microsoft 365 Copilot improve response quality?

- **A)** It translates the file to binary
- **B)** It grounds the LLM response in the explicit facts, figures, and context contained within that specific document (RAG pattern)
- **C)** It deletes the file after reading
- **D)** It uploads the document to public forums

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Document grounding utilizes Retrieval-Augmented Generation (RAG) to ensure the AI's output is factually tied to specific corporate files rather than generic web knowledge.

---

### Question 03
**Scenario / Problem Statement:**  
In Microsoft Excel, what type of tasks is Copilot best suited for?

- **A)** Rewriting kernel drivers
- **B)** Analyzing tabular data formatted as an official Excel Table, generating formula columns, highlighting trends, and building scenario charts
- **C)** Playing audio streams
- **D)** Bypassing network routers

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Copilot in Excel requires data to be formatted in an official Excel Table. It excels at data transformation, Python in Excel data analysis, and formula drafting.

---

### Question 04
**Scenario / Problem Statement:**  
When authoring an executive summary in Microsoft Word using Copilot, what is the best practice for refining the initial draft?

- **A)** Accepting the first output blindly
- **B)** Iteratively prompting Copilot to adjust tone, add missing sections from source presentations, and verifying cited figures manually
- **C)** Deleting the entire document
- **D)** Printing it to PDF immediately

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Generative AI output should always follow the 'Copilot, not Autopilot' principle: iterate with prompt refinements and verify critical metrics.

---

### Question 05
**Scenario / Problem Statement:**  
Which ethical responsibility must business professionals adhere to when utilizing AI-generated client deliverables?

- **A)** Attributing full legal liability to Microsoft
- **B)** Reviewing content for hallucinations, verifying factual accuracy, and maintaining confidentiality standards
- **C)** Claiming no AI was ever used
- **D)** Sharing sensitive customer data on open forums

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Professionals remain accountable for all deliverables; human verification of AI content is mandatory for compliance, accuracy, and brand reputation.
