## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
Which hybrid management service connects on-premises physical and virtual Windows Server 2025 machines directly to the Azure control plane for centralized policy, patch management, and Defender protection?

- **A)** Azure Arc-enabled servers
- **B)** Telnet client
- **C)** Local floppy disk
- **D)** Windows Media Player

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Azure Arc projects on-premises Windows Servers into Azure Resource Manager, enabling unified management with Azure Policy, Machine Configuration, and Microsoft Defender for Cloud.

---

### Question 02
**Scenario / Problem Statement:**  
In Windows Server 2025, which enhancement to Active Directory Domain Services (AD DS) improves database scalability and performance?

- **A)** 32k page size database support for the ESE/NTDS database engine
- **B)** Removal of all passwords
- **C)** Disabling DNS resolution
- **D)** Converting AD to MS Access format

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Windows Server 2025 introduces 32k page size support in the Extensible Storage Engine (ESE) database, dramatically boosting Active Directory performance on large directories.

---

### Question 03
**Scenario / Problem Statement:**  
Which disaster recovery and storage feature provides block-level, synchronous or asynchronous volume replication between Windows Server clusters across geographical sites?

- **A)** Storage Replica
- **B)** Windows Backup utility to tape
- **C)** Copy-paste in Explorer
- **D)** Zip file compression

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Storage Replica enables high-availability storage replication (synchronous zero-data-loss within metro latency or asynchronous across WAN distances) for failover clusters.

---

### Question 04
**Scenario / Problem Statement:**  
How does Windows Server 2025 'Hotpatching' benefit enterprise infrastructure operations?

- **A)** It overclocks server CPUs
- **B)** It installs security updates in-memory without requiring the server to reboot, dramatically maximizing uptime
- **C)** It warms up server cooling rooms
- **D)** It disables Windows updates entirely

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Hotpatching patches running code in-memory on supported Windows Server editions, reducing required monthly reboots and minimizing maintenance downtime.

---

### Question 05
**Scenario / Problem Statement:**  
Which protocol is enabled natively in Windows Server 2025 to secure file sharing over untrusted networks (such as the Internet) with encryption and TLS 1.3 encapsulation without needing a VPN?

- **A)** SMB over QUIC
- **B)** Plaintext FTP
- **C)** Telnet
- **D)** TFTP

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** SMB over QUIC provides secure, encrypted file access over UDP port 443 without requiring edge VPN gateways.
