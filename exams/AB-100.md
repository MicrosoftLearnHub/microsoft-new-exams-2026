## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
Which architectural capability in Microsoft Copilot Studio enables autonomous agents to dynamically select tools, chain APIs, and complete complex user workflows without predefined rigid dialog trees?

- **A)** Static Branch Nodes
- **B)** Dynamic Chaining (Generative AI Orchestrator)
- **C)** Hardcoded Bot Framework v3 Dialogs
- **D)** Windows Scheduled Tasks

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Dynamic Chaining allows the Copilot Studio generative orchestrator to analyze user intent, evaluate available plugin descriptions, and determine the optimal sequence of actions autonomously.

---

### Question 02
**Scenario / Problem Statement:**  
When connecting Copilot Studio agents to internal corporate data hosted on SharePoint, which authentication mechanism is mandatory for enforcing user-level security trimming?

- **A)** Anonymous / No Authentication
- **B)** Manual Entra ID Authentication with delegated permissions (Sites.Read.All)
- **C)** Static SQL Connection String
- **D)** Pre-shared API Key

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Configuring Entra ID manual authentication ensures that the agent accesses SharePoint content strictly on behalf of the signed-in user, respecting all underlying access rights and preventing security leakage.

---

### Question 03
**Scenario / Problem Statement:**  
In multi-agent collaborative workflows, what role does a supervisor/orchestrator agent play?

- **A)** It compiles C# binaries to WebAssembly
- **B)** It decomposes the primary user objective, delegates specialized subtasks to subordinate agents (e.g. Coder, Critic, Researcher), and synthesizes the final output
- **C)** It acts as a physical hardware firewall
- **D)** It formats hard drives

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** The supervisor agent acts as the multi-agent coordinator, breaking down complex multi-step problems, assigning specialized work to domain agents, and ensuring coherent final synthesis.

---

### Question 04
**Scenario / Problem Statement:**  
Which protocol allows AI agents to securely connect to external tools, databases, and enterprise services using a standardized interface?

- **A)** Model Context Protocol (MCP) and OpenAPI Plugin Standards
- **B)** POP3 Email Protocol
- **C)** Telnet Terminal Protocol
- **D)** FTP Port 21

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Standardized plugin architectures like MCP and OpenAPI allow AI agents to discover, negotiate capabilities with, and invoke external business tools securely.

---

### Question 05
**Scenario / Problem Statement:**  
What is the primary method for mitigating prompt injection and unauthorized execution in agent tool invocation?

- **A)** Allowing raw unvalidated user input directly into system shells
- **B)** Implementing strict input schema validation, content filtering, and Human-in-the-Loop (HITL) confirmation for sensitive mutations
- **C)** Turning off all logging
- **D)** Running agents on root privilege

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** HITL confirmations combined with rigorous parameter type checking and Azure AI Content Safety guardrails prevent malicious prompts from triggering destructive API actions without human oversight.
