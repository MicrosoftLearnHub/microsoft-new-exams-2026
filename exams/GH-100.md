## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
In GitHub Enterprise Cloud, which identity feature provisions and synchronizes developer user accounts directly from Microsoft Entra ID using the SCIM protocol?

- **A)** Enterprise Managed Users (EMU)
- **B)** Manual CSV upload
- **C)** Shared root password
- **D)** Anonymous pull access

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Enterprise Managed Users (EMU) enables organizations to manage user identities, access permissions, and lifecycle centrally via Microsoft Entra ID with SCIM automated provisioning.

---

### Question 02
**Scenario / Problem Statement:**  
Which GitHub feature automatically scans git commits for accidentally committed API keys, tokens, and private secrets, blocking the push before the secret enters repository history?

- **A)** Secret Scanning with Push Protection
- **B)** Code review comments
- **C)** Pull Request merge button
- **D)** Issue Tracker labels

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Secret Scanning Push Protection intercepts git push operations and blocks commits containing detected high-entropy credentials and tokens before they reach the remote repository.

---

### Question 03
**Scenario / Problem Statement:**  
In a GitHub Actions workflow, how should developers securely reference cloud credentials (like Azure or AWS access) without storing long-lived static secrets in GitHub?

- **A)** OpenID Connect (OIDC) federated credentials
- **B)** Hardcoding passwords in the YAML file
- **C)** Putting secrets in the commit message
- **D)** Uploading passwords to public Gists

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** GitHub Actions OIDC allows workflows to exchange short-lived tokens with cloud providers (Azure, AWS, GCP) using cloud workload identity federation, eliminating static long-lived credentials.

---

### Question 04
**Scenario / Problem Statement:**  
Which tool in GitHub Advanced Security (GHAS) performs automated static application security testing (SAST) to detect vulnerabilities like SQL injection and cross-site scripting in code?

- **A)** CodeQL code scanning
- **B)** Markdown linter
- **C)** Spelling checker
- **D)** Git rebase command

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** CodeQL treats source code as data, querying codebases for semantic patterns that match known Common Weakness Enumerations (CWEs) and security vulnerabilities.

---

### Question 05
**Scenario / Problem Statement:**  
How can enterprise administrators govern the use of GitHub Copilot to prevent public code matching and ensure IP protection?

- **A)** By enabling the 'Suggestions matching public code: Blocked' enterprise policy and managing Copilot license assignments centrally
- **B)** By asking developers to type faster
- **C)** By turning off internet access
- **D)** By disabling git version control

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** GitHub Enterprise allows administrators to enforce policies that block code suggestions matching public code repositories, ensuring compliance with organizational licensing policies.
