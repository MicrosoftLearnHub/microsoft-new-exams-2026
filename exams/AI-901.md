## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
Which Responsible AI principle requires that AI systems perform reliably and safely even when confronted with unexpected inputs or adversarial attacks?

- **A)** Reliability and Safety
- **B)** Transparency
- **C)** Fairness
- **D)** Inclusiveness

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Reliability and Safety mandates that AI solutions operate consistently within established operating boundaries, with robust error-handling and failure safeguards.

---

### Question 02
**Scenario / Problem Statement:**  
You are using Azure Machine Learning to build a model that predicts whether an incoming transaction is 'Fraudulent' or 'Legitimate'. What type of machine learning task is this?

- **A)** Binary Classification
- **B)** Regression
- **C)** Clustering
- **D)** Time-series forecasting

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Binary classification categorizes data into one of two mutually exclusive classes (Fraud vs Not Fraud, Yes vs No).

---

### Question 03
**Scenario / Problem Statement:**  
Which Azure AI service enables developers to train custom image classifiers and object detection models using a web-based GUI with minimal code?

- **A)** Azure AI Custom Vision
- **B)** Azure Virtual Network
- **C)** Azure Monitor
- **D)** Azure Cost Management

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Custom Vision allows developers to upload images, assign custom tags or bounding boxes, train vision models, and export them for deployment.

---

### Question 04
**Scenario / Problem Statement:**  
What is the primary role of Azure AI Language Sentiment Analysis?

- **A)** To predict future stock prices
- **B)** To evaluate text and return sentiment labels (positive, neutral, negative) along with confidence scores
- **C)** To translate audio to binary
- **D)** To format Word documents

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Sentiment Analysis assesses opinion and tone in text inputs to gauge customer feedback and review sentiments.

---

### Question 05
**Scenario / Problem Statement:**  
Which model family in Azure OpenAI is specialized for generating high-resolution visual artwork and images from natural language text prompts?

- **A)** DALL-E
- **B)** GPT-4
- **C)** Whisper
- **D)** text-embedding-3-small

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** DALL-E is OpenAI's image generation model, converting descriptive text prompts into original digital imagery.
