## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
What is the revolutionary advantage of 'Direct Lake' mode in Microsoft Fabric Power BI semantic models over traditional Import or DirectQuery modes?

- **A)** It copies data into memory every hour
- **B)** It queries Delta Parquet files in OneLake directly with in-memory VertiPaq performance without needing to import or refresh data
- **C)** It slows down queries to save power
- **D)** It only works offline

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Direct Lake mode reads Delta tables directly from OneLake storage into the VertiPaq analysis engine without duplicate caching or refresh latency, providing blazing-fast queries on petabytes of data.

---

### Question 02
**Scenario / Problem Statement:**  
Which architectural design framework structures data transformation into Bronze (raw ingestion), Silver (cleansed/standardized), and Gold (business-ready dimensional models)?

- **A)** Medallion Architecture
- **B)** Waterfall Architecture
- **C)** Monolithic Database Architecture
- **D)** Flat File Hierarchy

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** The Medallion architecture organizes data into progressively refined layers, ensuring high data quality, governance, and auditability.

---

### Question 03
**Scenario / Problem Statement:**  
You need to author a high-performance DAX measure that calculates year-to-date sales while ignoring existing date filters on the visual. Which DAX function combination is appropriate?",
- **A)** TOTALYTD(SUM(Sales[Amount]), 'Date'[Date]) and CALCULATE with ALL('Date')
- **B)** SUM without filters
- **C)** AVERAGE on text columns
- **D)** COUNTIF in Excel

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** DAX time-intelligence functions like TOTALYTD or CALCULATE(..., DATESYTD('Date'[Date]), ALL('Date')) allow robust calculation of cumulative metrics across dimensional models.

### Question 04
**Scenario / Problem Statement:**  
In Microsoft Fabric, how can analytics engineers maintain source code version control and CI/CD deployment for semantic models and notebooks?

- **A)** By saving files to desktop
- **B)** By integrating Fabric Workspaces with Git (Azure DevOps or GitHub) and deploying via Fabric Deployment Pipelines
- **C)** By taking photos of screens
- **D)** By sharing passwords

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Fabric workspaces natively connect to Azure DevOps and GitHub Git repositories, enabling source control, branch branching, and automated promotion across development, test, and production stages.

### Question 05
**Scenario / Problem Statement:**  
What is the purpose of Fabric Copilot in Power BI?

- **A)** To write low-level C code
- **B)** To assist analysts in authoring DAX measures, generating report pages from semantic models, and providing executive narrative summaries
- **C)** To browse social media
- **D)** To delete data models

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Copilot in Fabric and Power BI accelerates report creation by drafting DAX expressions, generating visual report layouts, and producing natural language summaries of business KPIs.
