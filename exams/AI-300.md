## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
In Azure Machine Learning, which open-source tracking standard is natively integrated for tracking experiment parameters, metrics, code versions, and model artifacts?

- **A)** MLflow
- **B)** GitLab CI only
- **C)** TensorBoard standalone without cloud
- **D)** CVS

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Azure ML integrates natively with MLflow, enabling standardized logging of hyperparameters, performance metrics, and model artifact registries across environments.

---

### Question 02
**Scenario / Problem Statement:**  
You need to execute an automated model retraining pipeline whenever new training data files land in an Azure Blob Storage container. How should you trigger the pipeline?

- **A)** Event-Driven Trigger using Azure Event Grid connected to Azure ML Pipeline endpoint
- **B)** Manual execution by a data scientist every morning
- **C)** Sleep command inside a shell loop
- **D)** Windows Scheduled Task on a developer laptop

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Event Grid monitors storage events (e.g., Blob Created) and automatically invokes the Azure ML Pipeline REST endpoint, enabling serverless automated retraining.

---

### Question 03
**Scenario / Problem Statement:**  
Which deployment target in Azure ML is recommended for high-throughput, mission-critical real-time inference with autoscaling and blue/green traffic splitting?

- **A)** Azure ML Managed Online Endpoints
- **B)** Local Docker Desktop on Mac
- **C)** Batch Endpoints running once a month
- **D)** Azure Static Web Apps

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Managed Online Endpoints take care of provisioning underlying compute, SSL certificates, autoscaling, blue/green rollout traffic splitting, and monitoring.

---

### Question 04
**Scenario / Problem Statement:**  
What is 'Data Drift' in machine learning operations?

- **A)** Physical movement of hard drives between data centers
- **B)** The statistically significant divergence between the distribution of production inference input data and the original baseline training data
- **C)** Typing errors in source code
- **D)** Slow network latency

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Data drift occurs when production input features shift over time compared to the training dataset, leading to degraded model accuracy and requiring retraining.

---

### Question 05
**Scenario / Problem Statement:**  
How do you implement responsible AI evaluation and guardrails in production LLM endpoints?

- **A)** By disabling all filters to save latency
- **B)** By integrating Azure AI Content Safety filters and configuring automated Prompt Flow evaluation metrics (Groundedness, Relevance, Toxicity)
- **C)** By restarting servers daily
- **D)** By running models on unauthenticated HTTP

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Azure AI Content Safety paired with Prompt Flow automated evaluation ensures outputs are screened for toxicity, jailbreak attempts, and factual hallucination.
