## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
In Microsoft Dataverse, which table type is best suited for storing structured transactional business records with relational integrity, roll-up columns, and row-level security?

- **A)** Standard Dataverse Table
- **B)** Unstructured text blob
- **C)** Static CSV file in OneDrive
- **D)** HTML web page

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Standard and Custom Dataverse tables provide enterprise relational data modeling, calculated and rollup fields, business rules, and granular security role mapping.

---

### Question 02
**Scenario / Problem Statement:**  
You need to trigger an automated workflow that runs whenever a new customer inquiry row is added to Dataverse and uses an AI Builder prompt to categorize customer sentiment. Which connector action should you use in Power Automate?

- **A)** When a row is added, modified or deleted (Dataverse connector) + Create text with GPT using a prompt (AI Builder connector)
- **B)** Send an email (V2)
- **C)** HTTP GET to Bing
- **D)** Delay for 5 minutes

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** The Dataverse automated trigger combined with AI Builder prompt actions allows serverless event-driven AI document and sentiment processing.

---

### Question 03
**Scenario / Problem Statement:**  
When building a canvas app in Power Apps, which control allows end users to converse naturally with an integrated agent grounded on enterprise Dataverse tables?

- **A)** Copilot control
- **B)** Timer control
- **C)** Barcode scanner control
- **D)** Audio player control

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** The Power Apps Copilot control provides a conversational interface that enables users to query data, ask questions, and trigger app actions in natural language.

---

### Question 04
**Scenario / Problem Statement:**  
How do you move intelligent applications, flows, and AI models across Dev, Test, and Production environments in Power Platform?

- **A)** By manually copying and pasting formula code
- **B)** By bundling all components into Managed Solutions and deploying them using Power Platform CLI or Azure DevOps / GitHub Pipelines
- **C)** By emailing zip files to colleagues
- **D)** By exporting screenshots

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Application Lifecycle Management (ALM) in Power Platform relies on Managed Solutions to cleanly package Dataverse tables, apps, cloud flows, and AI prompts for automated CI/CD deployment.

---

### Question 05
**Scenario / Problem Statement:**  
What is the primary benefit of using Custom Connectors in Power Automate and Power Apps when integrating with external microservices?

- **A)** It encrypts the entire user computer
- **B)** It exposes REST APIs with OpenAPI specifications as reusable actions and triggers across the entire low-code platform
- **C)** It turns off all security logging
- **D)** It replaces the Microsoft operating system

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Custom Connectors wrap OpenAPI (Swagger) endpoints, allowing low-code makers and Copilot agents to seamlessly invoke bespoke corporate microservices.
