## 🧠 5 Scenario-Based Practice Questions with In-Depth Explanations

### Question 01
**Scenario / Problem Statement:**  
When preparing an organization for Microsoft 365 Copilot, what is the most critical first step to prevent unauthorized data exposure through AI-generated answers?

- **A)** Deploy third-party firewalls around Teams servers
- **B)** Review and restrict overshared SharePoint sites using Microsoft Purview sensitivity labels and restricted access controls
- **C)** Revoke all user licenses and reissue them manually
- **D)** Disable search indexing on Exchange Online

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Over-permissioning and broad access (such as 'Everyone except external users') is the #1 security risk in generative AI deployments. Microsoft Purview data classification and SharePoint restricted access control prevent sensitive files from being indexed by Copilot.

---

### Question 02
**Scenario / Problem Statement:**  
Which admin portal is primarily used to assign Microsoft 365 Copilot licenses and view tenant-wide Copilot readiness and usage reports?

- **A)** Azure Portal exclusively
- **B)** Microsoft 365 Admin Center
- **C)** Power Automate Maker Studio
- **D)** Visual Studio Marketplace

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** The Microsoft 365 Admin Center (admin.microsoft.com) provides centralized license assignment, adoption score dashboards, and the Copilot Readiness Assessment.

---

### Question 03
**Scenario / Problem Statement:**  
An organization wants to configure custom agent capabilities for specific departments using natural language prompts without complex code. Which tool is designed for this within Microsoft 365?

- **A)** Copilot Studio Agent Builder (Lite)
- **B)** Azure Kubernetes Service
- **C)** Windows Terminal
- **D)** Visual Studio Code with C++

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Copilot Studio Agent Builder in Microsoft 365 allows business users to create tailored department agents directly within Teams and Copilot chat using guided prompts and connected SharePoint documents.

---

### Question 04
**Scenario / Problem Statement:**  
How does Microsoft 365 Copilot ensure tenant data isolation during LLM prompt processing?

- **A)** Prompts are publicly broadcast to consumer OpenAI servers
- **B)** Prompts and responses remain strictly within the customer's Microsoft 365 service boundary and are never used to train foundational AI models
- **C)** Data is cached in public blob storage for 90 days
- **D)** User prompts are forwarded to third-party advertisers

- **Correct Answer:** `B`
- **Detailed Architectural Explanation:** Microsoft 365 Copilot enforces enterprise privacy: customer data never leaves the tenant boundary, data is encrypted in transit and at rest, and tenant prompts/retrievals are never used to train foundation models.

---

### Question 05
**Scenario / Problem Statement:**  
Which Microsoft Purview feature enables security teams to audit Copilot interactions, detect prompt injection attempts, and monitor sensitive data sharing?

- **A)** Purview Audit (Premium) and Communication Compliance for Copilot
- **B)** Windows Defender Firewall
- **C)** System Center Configuration Manager
- **D)** Excel Solver

- **Correct Answer:** `A`
- **Detailed Architectural Explanation:** Microsoft Purview Audit and Communication Compliance capture Copilot prompt events, responses, and referenced item metadata to enforce regulatory compliance and forensic investigation.
