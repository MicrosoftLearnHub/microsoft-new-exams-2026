## 📌 Executive Summary: The 2026 Microsoft AI-First Credential Wave
In 2026, Microsoft rolled out its most significant certification restructuring to date, pivoting decisively toward **Agentic AI, Autonomous Copilots, Microsoft Fabric Unified Analytics, and Next-Gen Hybrid Infrastructure**.

Central to this wave is the new **AB-Series (Agentic & AI Business Solutions)**, introducing dedicated role-based credentials for AI agents, Copilot Studio orchestrators, and prompt engineering, alongside major new credentials in Microsoft Fabric (`DP-700`), Azure MLOps (`AI-300`), and Windows Server 2025 (`AZ-802`).

This repository is your **definitive technical handbook** covering blueprint breakdowns, domain weightings, candidate requirements, and scenario practice questions for every new and upcoming 2026 Microsoft exam.

## 🧭 Categorized Exam Tracks Overview

### 1. 🤖 The AB-Series: Agentic AI & Copilot Solutions
Microsoft's dedicated AI credential line covering autonomous agents, Copilot Studio, and business automation:
- **[AB-900: Copilot and Agent Administration Fundamentals](./exams/AB-900.md)** — Foundational management, data security, Purview compliance, and licensing for Microsoft 365 Copilot.
- **[AB-100: Agentic AI Business Solutions Architect](./exams/AB-100.md)** — Elite architecture of multi-agent orchestration, dynamic chaining, custom tools, and enterprise AI guardrails.
- **[AB-730: AI Business Professional](./exams/AB-730.md)** — Advanced prompt crafting, contextual grounding, and enterprise productivity across Word, Excel, PowerPoint, and Teams.
- **[AB-410: Intelligent Applications Builder Associate](./exams/AB-410.md)** — Low-code intelligent apps, Dataverse relational models, AI Builder prompts, and Power Automate workflows (successor to PL-200).
- **[AB-210: Dynamics 365 Sales AI Consultant Associate](./exams/AB-210.md)** — Autonomous sales agents (Research, Qualification, Close) and predictive pipelines in Dynamics 365 Sales.
- **[AB-250: Dynamics 365 Contact Center AI Engineer Associate](./exams/AB-250.md)** — AI-first omnichannel contact centers, voice IVR agents, unified routing, and real-time supervisor analytics.

### 2. 📊 Microsoft Fabric & Unified Data Engineering
- **[DP-700: Fabric Data Engineer Associate](./exams/DP-700.md)** — OneLake storage architecture, Delta Parquet format, shortcuts, real-time KQL intelligence, and Apache Spark pipelines.
- **[DP-600: Fabric Analytics Engineer Associate](./exams/DP-600.md)** — Direct Lake mode semantic models, DAX optimization, Medallion architecture, and enterprise Power BI reporting.

### 3. 🧠 Azure AI Workloads & Enterprise MLOps
- **[AI-901: Azure AI Fundamentals (2026 Refresh)](./exams/AI-901.md)** — Refreshed foundational exam covering Azure OpenAI models, multimodal vision, speech, NLP, and Responsible AI principles.
- **[AI-300: Machine Learning Operations (MLOps) Engineer Associate](./exams/AI-300.md)** — Automated training pipelines, MLflow integration, model drift detection, and secure endpoint serving.

### 4. ☁️ Modern Hybrid Cloud & DevOps Governance
- **[AZ-802: Windows Server Administrator Associate](./exams/AZ-802.md)** — Windows Server 2025 administration, Azure Arc hybrid governance, Hotpatching, Active Directory 32k DB, and SMB over QUIC.
- **[GH-100: GitHub Administration and Automation](./exams/GH-100.md)** — GitHub Enterprise Cloud/Server administration, Enterprise Managed Users (EMU), Actions CI/CD, and Copilot governance.

## 📐 General Microsoft Examination Rules & Scoring Guidelines

| Parameter | Standard Policy |
| :--- | :--- |
| **Passing Scaled Score** | **700 / 1000 points** (Scaled scoring ensures fair parity across question difficulties). |
| **Exam Duration** | Fundamentals: **60–90 Mins**; Associate & Specialty: **100–120 Mins**; Expert: **120–140 Mins**. |
| **Question Types** | Multiple Choice (Single/Multi-select), Drag-and-Drop, Case Studies, Sequence Ordering, Hot Areas. |
| **Beta Exam Scoring** | Beta exams are scored after the exam goes generally live (typically 8–12 weeks after beta release). |
| **Open Book Feature** | Associate and Expert role-based exams feature access to official Microsoft Learn documentation during the exam. |
